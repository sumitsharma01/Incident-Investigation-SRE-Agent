# LibreSRE symbol

`libresre-symbol.png` is the selected transparent symbol. The open ring represents
openness; the signal dip and settling line represent investigation and recovery.
The palette uses bright blue, navy and white. Keep clear space around the symbol
and avoid placing blue directly against a similar blue background.

The PNG was generated with imagegen from the brief: one open blue ring with an
integrated signal stroke, no text or tagline. It is a raster brand concept, not
an editable vector master or an assertion of trademark clearance. The runtime
copy lives in `app/workspace/brand/` so packaged and Docker installs include it.
